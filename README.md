# 20-20-20-Break-Timer
A super simple CLI  20-20-20 break timer to help prevent eye strain.



It works in a very simple way:

You open the app from the terminal.
It waits for 20 minutes.
A full-screen black screen appears with a countdown for a 20-second break.
It waits another 20 minutes.
Another 20-second break.
After another 20 minutes, it gives you a 5-minute break.
Then it starts the cycle again.

## Requirements

- Python 3
- Tkinter

## How to Use
- Download main.py
- Run it in terminal
